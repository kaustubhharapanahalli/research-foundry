# Security policy

## Supported versions

| Release line | Supported |
| ------------ | --------- |
| 0.1.x        | Yes       |
| Older lines  | No        |

Only the latest minor release line of the templates is supported. Security
fixes ship as patch releases, and existing projects take them with
`cruft update`.

## Reporting a vulnerability

Please report it privately, through GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository. Do not open a public issue.

Include the template, the file, and what an attacker could do. You will get a
reply within seven days.
