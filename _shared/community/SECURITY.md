# Security policy

## Supported versions

Only the latest release is supported. A security fix lands in a new release.

## Reporting a vulnerability

Please report it privately, through GitHub's
[private vulnerability reporting](https://github.com/{{ cookiecutter.github_owner }}/{{ cookiecutter.repo_name }}/security/advisories/new)
on this repository, or by email to {{ cookiecutter.contact_email }}. Do not
open a public issue.

Include the version, the affected file or function, and what an attacker
could do. You will get a reply within seven days.
